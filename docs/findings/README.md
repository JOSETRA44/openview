# Hallazgos

Cada afirmación lleva uno de estos niveles. No se mezclan.

| Nivel | Significado |
|---|---|
| **Verificado** | Leído en código o documentación primaria, o medido. Se cita el archivo o la fuente |
| **Tercero** | Lo afirma alguien con interés en el tema; no comprobado por nosotros |
| **Hipótesis** | Creemos que es así; falta la prueba, que se indica |
| **Límite** | Restricción conocida que el diseño debe asumir |
